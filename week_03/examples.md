# Примери 

## Пример 1

Разгледайте кода:

~~~cpp
int x = 0;

do {
    std::cout << x << " ";
    x += 2;
} while (x < 0);
~~~

Какво ще бъде изведено на екрана?

<details>
<summary>Покажи отговора</summary>

Ще се изведе:

~~~text
0
~~~

Тялото на `do...while` се изпълнява преди първата проверка на условието. Затова `0` се отпечатва, след което `x` става 2. Условието `2 < 0` е невярно и цикълът приключва.

</details>

---

## Пример 2

Разгледайте кода:

~~~cpp
int i = 0;

for (; i < 5; ++i);

std::cout << i;
~~~

Каква стойност ще бъде изведена?

<details>
<summary>Покажи отговора</summary>

Ще се изведе:

~~~text
5
~~~

Точката и запетаята след заглавието на `for` е празното тяло на цикъла. Цикълът само увеличава `i`:

`i = 0`, `i = 1`, `i = 2`, `i = 3`, `i = 4`.

След последното увеличение `i` става 5 и условието `i < 5` вече е невярно.

</details>

## Пример 3

Разгледайте кода:

~~~cpp
for (int row = 0, column = 7; row < column; ++row, --column) {
    // тяло на цикъла
}
~~~

Какъв е типът на променливите `row` и `column` в тази декларация?

<details>
<summary>Покажи отговора</summary>

И двете променливи са от тип `int`. Когато няколко променливи се декларират в една декларация, те са от един и същи тип:

~~~cpp
int row = 0, column = 7;
~~~

</details>

## Пример 4

Разгледайте кода:

~~~cpp
for (int left = 1, right = 7;
     left < right;
     ++left, right -= 2) {
    std::cout << left + right << " ";
}
~~~

Какво ще бъде изведено на екрана?

<details>
<summary>Покажи отговора</summary>

Ще се изведе:

~~~text
8 7
~~~

Проследяване:

| `left` | `right` | Отпечатана стойност |
|---:|---:|---:|
| 1 | 7 | 8 |
| 2 | 5 | 7 |

След втората итерация променливите стават `left = 3` и `right = 3`. Условието `left < right` вече е невярно.

</details>

## Пример 5

Разгледайте кода:

~~~cpp
int x = 8, y = 3;

while (x > 0) {
    if (x % y == 0) {
        break;
    } else {
        x -= 1;
    }
}

std::cout << x;
~~~

Каква стойност ще бъде изведена на екрана?

<details>
<summary>Покажи отговора</summary>

Ще се изведе:

~~~text
6
~~~

При `x = 8` и `x = 7` остатъкът при деление на 3 не е нула, затова `x` намалява.

При `x = 6` условието `6 % 3 == 0` е вярно. Изпълнява се `break` и цикълът приключва.

</details>

## Пример 6

Разгледайте кода:

~~~cpp
for (int i = 2; i <= 4; ++i) {
    for (int j = 4; j > 1; --j) {
        std::cout << (i + j);
    }

    std::cout << std::endl;
}
~~~

Какво ще бъде изведено на екрана?

<details>
<summary>Покажи отговора</summary>

Ще се изведе:

~~~text
654
765
876
~~~

За всяка стойност на `i` вътрешният цикъл преминава през стойностите `j = 4`, `j = 3` и `j = 2`.

Тъй като между стойностите няма разделител, те се отпечатват непосредствено една след друга на същия ред.

</details>

## Пример 7

Разгледайте кода:

~~~cpp
for (int i = 1; i <= 8; i *= 2) {
    std::cout << i << " ";

    if (i == 2) {
        i += 1;
    }
}
~~~

Какво ще бъде изведено на екрана?

<details>
<summary>Покажи отговора</summary>

Ще се изведе:

~~~text
1 2 6
~~~

След отпечатването на `1` изразът за промяна на цикъла прави `i = 2`.

След отпечатването на `2` условието променя стойността на `i` на 3. След това се изпълнява и изразът за промяна на `for`, който умножава `i` по 2. Така `i` става 6.

След отпечатването на `6` стойността става 12 и условието `i <= 8` вече е невярно.

</details>

## Пример 8

Разгледайте кода:

~~~cpp
int n, x, sum;

for (n = 1; n <= 4; ++n) {
    for (sum = 0, x = 0; x < n; ++x) {
        sum += n;
    }
}

std::cout << sum << std::endl;
~~~

Каква стойност ще бъде изведена?

<details>
<summary>Покажи отговора</summary>

Ще се изведе:

~~~text
16
~~~

При всяко ново изпълнение на вътрешния цикъл `sum` се нулира. След това към него се прибавя стойността на `n` точно `n` пъти.

| Стойност на `n` | Брой изпълнения на вътрешния цикъл | Крайна стойност на `sum` |
|---:|---:|---:|
| 1 | 1 | 1 |
| 2 | 2 | 4 |
| 3 | 3 | 9 |
| 4 | 4 | 16 |

След последното изпълнение на вътрешния цикъл стойността на `sum` е 16.

</details>

## Пример 9

Разгледайте кода:

~~~cpp
int n = 1;

for (;;) {
    if (n * n > 20) {
        break;
    }

    std::cout << n << " ";
    ++n;
}
~~~

Какво ще бъде изведено на екрана?

<details>
<summary>Покажи отговора</summary>

Ще се изведе:

~~~text
1 2 3 4
~~~

`for (;;)` създава цикъл без условие за приключване. Той се прекратява, когато `n * n` стане по-голямо от 20.

При `n = 5` условието `5 * 5 > 20` е вярно и се изпълнява `break`. Числото 5 не се отпечатва.

</details>

## Пример 10

Разгледайте кода:

~~~cpp
int total = 0;

for (int i = 1; i <= 3; ++i) {
    for (int j = 1; j <= 3; ++j) {
        total += i;

        if (total > 5) {
            break;
        }
    }

    std::cout << total << " ";
}
~~~

Какво ще бъде изведено на екрана?

<details>
<summary>Покажи отговора</summary>

Ще се изведе:

~~~text
3 7 10
~~~

При `i = 1` вътрешният цикъл се изпълнява три пъти и `total` става 3.

При `i = 2` стойностите на `total` стават 5, а след това 7. При 7 се изпълнява `break` и вътрешният цикъл приключва.

При `i = 3` още първото прибавяне прави `total` равно на 10 и вътрешният цикъл отново приключва.

`break` прекратява само вътрешния цикъл. Външният цикъл продължава да се изпълнява.

</details>

## Пример 11

Разгледайте кода:

~~~cpp
int x = 6, y = 4;

do {
    if (x % y == 0) {
        continue;
    }

    x -= 1;
    y = y + 1;
} while (x > 0);

std::cout << y;
~~~

Какво ще се случи при изпълнението на този код?

<details>
<summary>Покажи отговора</summary>

Цикълът няма да приключи и до `std::cout` няма да се стигне.

Първоначално `x = 6` и `y = 4`. Понеже `6 % 4 != 0`, се изпълняват редовете след условието:

~~~text
x = 5
y = 5
~~~

При следващата итерация условието `5 % 5 == 0` е вярно и се изпълнява `continue`.

При `do...while` операторът `continue` преминава към проверката на условието и пропуска редовете, които променят `x` и `y`. Стойностите остават `x = 5` и `y = 5`.

Условието `x > 0` продължава да бъде вярно, затова се получава безкраен цикъл.

</details>
