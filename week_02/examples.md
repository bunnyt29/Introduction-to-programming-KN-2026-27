# C++: Префиксни и постфиксни оператори (`++` и `--`)

## Примери за часа

**Задача:** За всеки пример първо определете какво ще изведе програмата, без да я стартирате. След това разгънете **„Покажи изхода“**, за да проверите отговора си.

> **Припомняне:** `++i` и `--i` първо променят стойността, след което тя се използва. `i++` и `i--` първо дават старата стойност за текущия израз, след което променят променливата.
>

---

### Пример 1 — Префиксен инкремент (`++i`)

```cpp
int i = 5;
int a = ++i;

cout << i << endl;
cout << a << endl;
```

<details>
<summary>Покажи изхода</summary>

```text
6
6
```

</details>

---

### Пример 2 — Постфиксен инкремент (`i++`)

```cpp
int i = 5;
int a = i++;

cout << i << endl;
cout << a << endl;
```

<details>
<summary>Покажи изхода</summary>

```text
6
5
```

</details>

---

### Пример 3 — Префиксен инкремент в аритметичен израз

```cpp
int a = 3;
int b = 2 * ++a;

cout << a << " " << b;
```

<details>
<summary>Покажи изхода</summary>

```text
4 8
```

</details>

---

### Пример 4 — Постфиксен инкремент в аритметичен израз

```cpp
int a = 3;
int b = 2 * a++;

cout << a << " " << b;
```

<details>
<summary>Покажи изхода</summary>

```text
4 6
```

</details>

---

### Пример 5 — Последователни инкременти и декременти

```cpp
int x = 5;

int a = x++;
int b = ++x;
int c = x--;

cout << x << " " << a << " " << b << " " << c;
```

<details>
<summary>Покажи изхода</summary>

```text
6 5 7 7
```

</details>

---

### Пример 6 — Инкременти при извеждане с `cout`

```cpp
int x = 10;

cout << x++ << endl;
cout << ++x << endl;
cout << x << endl;
```

<details>
<summary>Покажи изхода</summary>

```text
10
12
12
```

</details>

---

### Пример 7 — Комбинирани операции с две променливи

```cpp
int x = 2;
int y = 5;

int a = x++ + y--;
int b = ++x * --y;
int c = a + b + x;

cout << x << " " << y << " " << a
     << " " << b << " " << c;
```

<details>
<summary>Покажи изхода</summary>

```text
4 3 7 12 23
```

</details>

---

### Пример 8 — Инкремент и логически сравнения

```cpp
int a = 4;
int b = 5;

bool x = (++a == b);
bool y = (a++ > b);

std::cout << a << " " << b << " " << x << " " << y;
```

<details>
<summary>Покажи изхода</summary>

```text
6 5 1 0
```

</details>
