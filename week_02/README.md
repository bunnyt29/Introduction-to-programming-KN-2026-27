# Типове данни, оператори и условни конструкции

## 1. Основни типове данни

| Тип | Описание | Размер в паметта |
| :--- | :--- | :--- |
| `short` | Малки цели числа | 2 байта |
| `int` | Стандартни цели числа | 4 байта |
| `long` / `long long` | Големи цели числа | 4 / 8 байта |
| `unsigned` (`unsigned int`, ...) | Цели неотрицателни числа (0 и положителни) | същият като съответния тип |
| `float` | Реални числа с единична точност (~7 знака) | 4 байта |
| `double` | Реални числа с двойна точност (~15-17 знака) | 8 байта |
| `char` | Единичен символ (в паметта се пази като ASCII код) | 1 байт |
| `bool` | Булева стойност (`true` / `false`) | 1 байт |

## 2. Оператори

### Аритметични оператори
* `+`, `-`, `*` — събиране, изваждане, умножение
* `/` — деление:
  * **целочислено:** ако делим цели числа (`7 / 2` е `3`)
  * **реално:** ако поне едното е с плаваща запетая (`7.0 / 2` е `3.5`)
* `%` — остатък при деление (работи **само за цели числа**, `7 % 2` е `1`)
* `++`, `--` — увеличаване / намаляване с 1:
  * префиксно (`++x`): първо променя стойността, после я връща
  * постфиксно (`x++`): първо връща старата стойност, после я променя

### Оператори за сравнение
Винаги връщат `bool` (`true` или `false`):
* `==`, `!=` (равно, различно)
* `<`, `>`, `<=`, `>=`

### Логически оператори
* `&&` — логическо И (и двете трябва да са верни)
* `||` — логическо ИЛИ (поне едното трябва да е вярно)
* `!` — отрицание (`!true` става `false`)

#### Интересно
> При `&&` и `||` C++ спира да проверява условията в момента, в който крайният резултат е ясен (short-circuit). Например в `(x != 0 && 100 / x > 2)`, ако `x` е 0, дясната част изобщо няма да се изпълни и програмата няма да гръмне с деление на нула.

### Оператори за присвояване
* `=`, `+=`, `-=`, `*=`, `/=`, `%=`
* `a += 5;` е съкратен запис за `a = a + 5;`

### Тернарен оператор (`?:`)
Кратък условен израз на един ред:
```cpp
int max = (a > b) ? a : b;
```

## 3. Условни конструкции

### `if`, `else if`, `else`
Всяко число, различно от 0, се приема за `true`, а `0` — за `false`. Внимавайте да не пишете случайно `=` (присвояване) вместо `==` (сравнение) в условието.

```cpp
if (условие_1) {
    // код при условие_1
} else if (условие_2) {
    // код при условие_2
} else {
    // код, ако никое от горните не е истина
}
```

### `switch`
Удобен при проверка на една променлива срещу множество фиксирани стойности. Работи само с цели числа и символи (`int`, `char`, и др.). Не работи с реални числа (`float`, `double`).

* Всеки `case` завършва с `break;`, за да се прекрати изпълнението на `switch`-а.
* `default` се изпълнява, когато никоя от посочените стойности не съвпадне.

**Стандартен пример:**
```cpp
int choice = 1;

switch (choice) {
    case 1:
        std::cout << "Старт\n";
        break;
    case 2:
        std::cout << "Изход\n";
        break;
    default:
        std::cout << "Невалиден избор\n";
        break;
}
```

#### Обединяване на няколко `case`-а
Можем умишлено да обединяваме няколко `case`-а да изпълняват един и същ код, като просто не слагаме `break` между тях:

```cpp
switch (number) {
    case 2:
    case 4:
    case 6:
        std::cout << "even\n";
        break;
    case 1:
    case 3:
    case 5:
        std::cout << "odd\n";
        break;
    default:
        std::cout << "other\n";
        break;
}
```

#### Забравен `break;` (fall-through капан)
Ако пропуснем `break;`, изпълнението не спира, а продължава надолу и изпълнява кода на следващите `case`-ове, дори тяхното условие изобщо да не е изпълнено!

**Пример 1: Изпълнение на следващите съседни случаи**
```cpp
int x = 1;

switch (x) {
    case 1:
        std::cout << "One\n";
        // забравен break!
    case 2:
        std::cout << "Two\n";
        // забравен break!
    case 3:
        std::cout << "Three\n";
        break;
}

// Изход:
// One
// Two
// Three
// Въпреки че x е само 1, се изпълнява и кодът за 2 и 3, понеже след влизането в case 1 нищо не спира изпълнението.
```

**Пример 2: Неволно изпълнение на `default`**
```cpp
char grade = 'A';

switch (grade) {
    case 'A':
        std::cout << "Отличен!\n";
        // забравен break!
    default:
        std::cout << "Невалидна оценка!\n";
        break;
}

// Изход:
// Отличен!
// Невалидна оценка!
// Студентът получава и „Отличен!“, и съобщението за невалидна оценка от default.
```
