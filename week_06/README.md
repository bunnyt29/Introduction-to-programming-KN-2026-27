# Масиви и матрици в C++

## 1. Дефиниране и инициализация

```cpp
const unsigned MAX_SIZE = 128;

// Едномерен масив:
int arr[MAX_SIZE];                  // стойности по подразбиране (боклук в стека)
int arr2[5] = {1, 2, 3, 4, 5};      // с начални стойности
int arr3[MAX_SIZE] = {0};           // всички елементи са 0

// Двумерен масив (матрица):
int matrix[MAX_SIZE][MAX_SIZE];
int matrix2[2][3] = { {1, 2, 3}, {4, 5, 6} };
```

---

## 2. Въвеждане от потребителя

```cpp
// 1D:
unsigned n;
std::cin >> n;
for (unsigned i = 0; i < n; ++i) {
    std::cin >> arr[i];
}

// 2D:
unsigned rows, cols;
std::cin >> rows >> cols;
for (unsigned i = 0; i < rows; ++i) {
    for (unsigned j = 0; j < cols; ++j) {
        std::cin >> matrix[i][j];
    }
}
```

## 3. Array-to-Pointer Decay

Когато подадем масив на функция, неговото име **автоматично се разпада (decays) до указател към първия му елемент**:

- `int arr[]` $\rightarrow$ компилаторът го преобразува в `int* arr`.
- `int matrix[][MAX_COLS]` $\rightarrow$ компилаторът го преобразува в `int (*matrix)[MAX_COLS]` (указател към масив от фиксиран брой колони).

```cpp
void printArr(int arr[], unsigned size);             // идентично с: void printArr(int* arr, unsigned size);
void printMatrix(int matrix[][128], unsigned r, unsigned c); // идентично с: void printMatrix(int (*matrix)[128], ...);
```

---

## 4. Защо НЕ пишем `&` или `*` при подаване?

Масивът **не се копира**. Тъй като името му вече се разпада до указател към оригиналната памет:
1. Всяка промяна на елемент вътре във функцията (`arr[i] = 10;`) **променя директно оригиналния масив**.
2. **Няма овърхед от копиране** — предава се само адрес.
3. Ако искаме да гарантираме, че функцията няма да го променя, използваме `const`:
   ```cpp
   void print(const int arr[], unsigned size);
   void print2D(const int matrix[][MAX_SIZE], unsigned rows, unsigned cols);
   ```

---

## 5. Защо за матрица са задължителни колоните?

В паметта матрицата е **1D непрекъснат блок** (Row-Major order). Адресът на клетка `[i][j]` се изчислява така:
$$\text{Адрес} = \text{Start} + (i \cdot \mathbf{COLS} + j) \cdot \text{sizeof}(\text{тип})$$

- Компилаторът **трябва да знае броя колони ($\mathbf{COLS}$)**, за да знае с колко клетки да прескочи при смяна на реда ($i \rightarrow i+1$).
- Броят редове не участва във формулата за отместване и затова не се оказва в типа на параметъра.

---

## 6. Важни правила накратко

1. **Размерът винаги се подава отделно:** Масивът „губи“ информация за дължината си при подаване на функция. Винаги подавайте реалния брой елементи като параметър (`size` / `rows`, `cols`).
2. **Внимавайте с границите:** C++ **не проверява** дали излизате извън масива (`OutOfBounds`). Достъп извън границите води до *Undefined Behavior*.
