# Увод в програмирането (УП) — КН 2026/2027

Материали за практикума по „Увод в програмирането“ за специалност **Компютърни науки** (поток 2), Факултет по математика и информатика (ФМИ), СУ „Св. Климент Охридски“.

---

## Разглеждани теми

- [**Седмица 1**](week_01) — Въведение в Git и GitHub. Основни типове данни, вход и изход, аритметични операции.
- [**Седмица 2**](week_02) — Оператори за сравнение, логически операции, условни конструкции.
- [**Седмица 3**](week_03) — Цикли (`for`, `while`, `do...while`). Управление на цикли (`break`, `continue`).
- [**Седмица 4**](week_04) — Указатели, адресни операции (`&`, `*`), псевдоними/референции, подаване на параметри по стойност и референция.
- [**Седмица 5**](week_05) — Функции. (`lvalue` и `rvalue`). Разделяне на код на функции.
- [**Седмица 6**](week_06) — Едномерни и многомерни масиви (матрици).
