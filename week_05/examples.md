# Примери: функции, референции и указатели

## Пример 1

~~~cpp
#include <iostream>

void modify(int a, int& b, int* p) {
    a += 2;
    b += a;
    *p = b - a;
}

int main() {
    int x = 3;
    int y = 5;

    modify(x, y, &x);
    modify(y, x, &y);

    std::cout << x << " " << y << std::endl;
}
~~~

Какво ще изведе програмата и защо?

<details>
<summary>Покажи отговора</summary>

Програмата ще изведе:

~~~text
17 5
~~~

При първото извикване `a` е копие на `x` и става 5. Референцията `b` променя `y` на 10, а указателят `p` променя `x` на 5.

При второто извикване `a` е копие на `y` и става 12. Референцията `b` променя `x` на 17, а указателят `p` променя `y` на 5.

</details>

## Пример 2

~~~cpp
#include <iostream>

void change(int& x) {
    x += 3;
}

void print(const int& x) {
    std::cout << x << " ";
}

int main() {
    int a = 4;
    const int b = 10;

    change(++a);
    // change(a++);
    // change(b);
    // change(a + 2);

    print(a++);
    print(a + 1);
    print(b);

    std::cout << a << std::endl;
}
~~~

Какво ще изведе програмата и кои коментирани редове могат да се разкоментират?

<details>
<summary>Покажи отговора</summary>

Програмата ще изведе:

~~~text
8 10 10 9
~~~

`++a` увеличава `a` на 5 и връща самата променлива, затова може да се подаде към `int&`. След `change` стойността на `a` е 8. `print(a++)` извежда 8 и след това увеличава `a` на 9. Следващите две извиквания извеждат 10 и 10.

Нито един от коментираните редове не може да се разкоментира. `a++` и `a + 2` са временни стойности, а `b` е константа. Те не могат да се свържат с неконстантна референция `int&`. Константната референция `const int&` във `print` може да приема такива стойности.

</details>

## Пример 3

~~~cpp
#include <iostream>

int& choose(int& a, int& b) {
    if (a > b) {
        return a;
    }

    return b;
}

int main() {
    int x = 4;
    int y = 9;

    int& a = choose(x, y);

    x = 15;
    a += 3;

    int& b = choose(x, y);
    b = a;

    std::cout << x << " " << y << " "
              << a << " " << b << std::endl;
}
~~~

Какво ще изведе програмата и защо?

<details>
<summary>Покажи отговора</summary>

Програмата ще изведе:

~~~text
12 12 12 12
~~~

Първата референция `a` се свързва с `y`. След `x = 15` и `a += 3` стойностите са `x = 15` и `y = 12`.

Втората референция `b` се свързва с `x`. Изразът `b = a` не пренасочва референцията, а присвоява стойността на `y` към `x`. Така и двете променливи стават 12.

</details>

## Пример 4

~~~cpp
#include <iostream>

int& getReference() {
    int value = 10;
    return value;
}

int getValue() {
    int value = 20;
    return value;
}

int main() {
    int& a = getReference();
    int b = getValue();

    b += 5;

    std::cout << b << std::endl;
    std::cout << a << std::endl;
}
~~~

Ще се компилира ли програмата и какво ще се случи при изпълнението ѝ?

<details>
<summary>Покажи отговора</summary>

Програмата обикновено ще се компилира, но компилаторът вероятно ще изведе предупреждение. При изпълнението се стига до неопределено поведение.

`getValue` връща копие и `b` получава собствена стойност. След увеличението тя е 25.

`getReference` връща референция към локална променлива, която вече не съществува след края на функцията. Така `a` е висяща референция и прочитането ѝ няма гарантиран резултат.

</details>

## Пример 5

~~~cpp
#include <iostream>

const int& getMax(const int& a, const int& b) {
    return a > b ? a : b;
}

int main() {
    int x = 5;

    const int& a = getMax(x, 10);
    const int& b = getMax(x, 3);

    x = 20;

    std::cout << a << " " << b << std::endl;
}
~~~

Ще се компилира ли програмата и какво ще се случи при изпълнението ѝ?

<details>
<summary>Покажи отговора</summary>

Програмата ще се компилира, но при изпълнението се стига до неопределено поведение.

При `getMax(x, 10)` се връща референция към временния обект със стойност 10. Този обект престава да съществува след края на израза и `a` става висяща референция.

При `getMax(x, 3)` се връща референция към `x`, затова `b` остава валидна и след `x = 20` има стойност 20. Прочитането на `a` обаче означава, че крайният изход не е гарантиран.

</details>

## Пример 6

~~~cpp
#include <iostream>

void redirect(int* p, int** q, int& v) {
    p = &v;
    **q += 2;
    *q = p;
}

int main() {
    int a = 4;
    int b = 10;

    int* ptr = &a;

    redirect(ptr, &ptr, b);
    *ptr += 3;

    std::cout << a << " " << b << std::endl;
}
~~~

Какво ще изведе програмата и защо?

<details>
<summary>Покажи отговора</summary>

Програмата ще изведе:

~~~text
6 13
~~~

`p` получава копие на `ptr`, `q` сочи към самия `ptr`, а `v` е референция към `b`. Пренасочването на `p` към `b` засяга само локалното копие.

`**q += 2` увеличава `a` от 4 на 6. След това `*q = p` пренасочва оригиналния указател `ptr` към `b`, а `*ptr += 3` увеличава `b` от 10 на 13.

</details>
