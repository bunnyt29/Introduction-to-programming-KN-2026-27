# Седмица 1 — Задачи

## Задача 1

Да се въведат от потребителя две цели числа и да се изведат на екрана техните: сума, разлика, произведение, както и частното и остатъкът при целочислено деление на първото число на второто.

**Example 1:**

```
Input: 14 4
Output:
Сума: 18
Разлика: 10
Произведение: 56
Частно: 3
Остатък: 2
```

---

## Задача 2

Да се напише програма, която при въведено от потребителя цяло число отпечатва 1 (или true), ако то е четно, и 0 (или false), ако е нечетно.

**Example 1:**

```
Input: 8
Output: 1
```

---

## Задача 3

Да се напише програма, която въвежда символ от клавиатурата и отпечатва неговия ASCII код.

**Example 1:**

```
Input: a
Output: 97
```

---

## Задача 4

Да се напише програма, която въвежда две реални числа (с плаваща запетая) `a` и `b` и разменя техните стойности:
- а) чрез помощна променлива;
- б) чрез аритметични операции.

**Example 1:**

```
Input: 5.5 2.1
Output:
Преди размяна: a = 5.5, b = 2.1
След размяна: a = 2.1, b = 5.5
```

---

## Задача 5

Да се напише програма, която въвежда положително четирицифрено число и извежда цифрите му в обратен ред, разделени със символа `-`.

**Example 1:**

```
Input: 1234
Output: 4-3-2-1
```

## Задача 6

Да се въведат три положителни цели числа (от тип `unsigned int`) `a`, `b` и `c`. Програмата да отпечата 1 (или true), ако те могат да образуват валиден триъгълник, и 0 (или false) в противен случай.

**Example 1:**

```
Input: 3 4 5
Output: 1
```
