# Указатели и референции в C++

Всяка програма работи с данни, разположени в оперативната памет (RAM) на компютъра. Досега дефинирахме променливи и достъпвахме техните стойности пряко чрез техните имена. За да разберем как функционира паметта на по-ниско ниво, е необходимо да разгледаме понятията **адрес**, **указател** и **референция**.

---

## 1. Организация на оперативната памет

1. **Бит (bit):** Най-малката единица информация в изчислителната техника — приема стойност **0** или **1**.
2. **Байт (byte):** Поредица от **8 бита** ($2^8 = 256$ възможни състояния).
3. **Адресируемост:** Байтът е **най-малката адресируема единица** в паметта. Оперативната памет представлява непрекъсната последователност от байтове, като всеки байт притежава уникален пореден номер — своя **адрес в паметта** (обикновено се изписва в шестнадесетичен формат, напр. `0x7ffd9b...`).

### Размери на примитивните типове данни

При дефиниране на променлива компилаторът заделя за нея определен брой последователни байтове според нейния тип (`sizeof`):

| Тип | Размер |
| :--- | :--- |
| `char`, `bool` | **1 байт**
| `short` | **2 байта**
| `int`, `float` | **4 байта**
| `double`, `long long` | **8 байта**
---

## 2. Какво е указател (Pointer)?

* **Указателят е променлива**, чиято стойност представлява **адрес** на друга променлива.

Досега променливите ни съхраняваха директни стойности (символ `'A'`, цяло число `42`). Указателят е променлива от нов вид — неговото предназначение е да съхранява адреса (номера на байта) в паметта, на който се намира друга променлива.

### Синтаксис

~~~cpp
тип* име_на_указателя;
~~~

Символът `*` до типа показва, че декларираме указател към съответния тип данни:

~~~cpp
int* pInt;       // указател към цяло число
char* pChar;     // указател към символ
double* pDouble; // указател към число с плаваща запетая
~~~

> **Позиция на звездичката:** За компилатора записите `int* p;`, `int *p;` и `int * p;` са напълно еквивалентни.

### Размер на указателя

Тъй като указателят съхранява адрес в паметта, неговият размер зависи единствено от архитектурата на компютъра, а не от типа данни, към който сочи:

* При **64-битова архитектура** всеки адрес е с дължина 64 бита (8 байта), следователно **всеки указател заема точно 8 байта**:
  ~~~cpp
  sizeof(char*)   == 8;
  sizeof(int*)    == 8;
  sizeof(double*) == 8;
  ~~~
---


## 3. Оператор `&` (взимане на адрес)

След като вече знаем какво представлява указателят, възниква въпросът: как да вземем адреса на реална променлива, за да го съхраним в указател?

За целта използваме **оператора `&`**, който се поставя пред името на променливата:

~~~cpp
int number = 42;
int* ptr = &number; // ptr записва адреса на number

std::cout << "Стойност на number: " << number << "\n";         // 42
std::cout << "Адрес на number (&number): " << &number << "\n"; // напр. 0x7ffd9b24
std::cout << "Стойност на ptr: " << ptr << "\n";               // 0x7ffd9b24 (същият адрес!)
std::cout << "Собствен адрес на ptr (&ptr): " << &ptr << "\n"; // напр. 0x7ffd9b28
~~~

---

## 4. Оператор `*` (дереференциране / достъп по адрес)

След като указателят вече съхранява адреса на дадена променлива, как можем да достигнем до стойността, намираща се на този адрес?

Това става чрез **оператора `*`**, поставен пред указателя. Това действие се нарича **дереференциране**:

* Чрез `*ptr` осъществяваме пряк достъп до оригиналната променлива — както за **четене**, така и за **модификация**:

~~~cpp
int number = 10;
int* ptr = &number;

// 1. Четене през указател:
int result = *ptr;
std::cout << result << "\n"; // 10

// 2. Модификация през указател:
*ptr = 25; // Променя стойността директно на адрес &number
std::cout << number << "\n"; // 25
~~~

---

## 5. Нулев указател (`nullptr`)

`nullptr` е специална стойност, която показва, че указателят не сочи към нищо (празен е). Използва се за безопасна инициализация, за да не съдържа случаен адрес от паметта:

~~~cpp
int* ptr = nullptr; // Безопасен, неинициализиран с адрес указател
~~~
---

## 6. Референции (References / Псевдоними)

**Референцията** е алтернативно име (псевдоним) за вече съществуваща променлива. За разлика от указателя, референцията **не е отделна променлива** в паметта и няма собствен адрес — тя споделя адреса и стойността на оригиналната променлива.

### Синтаксис

~~~cpp
тип& име_на_референцията = променлива;
~~~

~~~cpp
int original = 5;
int& ref = original; // ref е псевдоним на original

ref = 20; // Променя стойността на original
std::cout << original << "\n"; // 20
std::cout << &original << " == " << &ref << "\n"; // Адресите им са напълно идентични
~~~

---

## 7. Сравнение между указател и референция

| Свойство | Указател | Референция |
| :--- | :--- | :--- |
| **Същност** | Променлива, съхраняваща адрес в паметта (8 байта). | Алтернативно име (псевдоним) за съществуваща променлива. |
| **Инициализация** | Може да се дефинира без стойност или с `nullptr`. | **Задължително** се инициализира при създаването (`int& r;` е грешка). |
| **Пренасочване** | Може да се пренасочва към друг адрес по всяко време (`ptr = &b;`). | **Не може** да се пренасочва след първоначалното свързване. |
| **Неутрална стойност** | Притежава стойност `nullptr`. | **Няма** неутрална стойност (винаги реферира реален обект). |
| **Синтаксис за достъп** | Изисква явно дереференциране чрез оператора `*`. | Използва се директно с името си, както обикновена променлива. |
| **Собствен адрес** | Притежава собствен адрес в паметта (`&ptr != &num`). | Няма собствен адрес — `&ref` дава адреса на оригиналния обект. |

---

## 8. Пренасочване на указател vs. Присвояване през референция

Често допускано объркване при работа с указатели и референции:

~~~cpp
int a = 10;
int b = 20;

// 1. Поведение при указател:
int* p = &a;
p = &b;       // p вече съхранява адреса на b (стойността на a остава 10)

// 2. Поведение при референция:
int& r = a;
r = b;        // Това НЕ свързва r с b!
              // Изразът е еквивалентен на: a = b; (стойността на a става 20)
~~~

## 9. Модификаторът `const` при указатели и референции

Ключовата дума `const` се използва за защита от нежелана модификация. При указателите обаче има **две напълно различни неща**, които могат да бъдат константни:
1. **Самият указател** (адресът, към който сочи — дали можем да го пренасочим).
2. **Стойността**, към която сочи (данните на този адрес — дали можем да ги променяме през `*ptr`).

---

### Четем отдясно-наляво

За да разберете какво прави дадена декларация, просто я **четете отдясно-наляво** (започвайки от името на променливата)

1. **`const` е ВЛЯВО от звездичката `*` $\to$ Данните са константа (Указател към константа):**
   ~~~cpp
   const int* ptr = &a; // еквивалентно на: int const* ptr = &a;
   ~~~
   * **Четене отдясно-наляво:** `ptr` е указател (`*`) към константно цяло число (`const int`).
   * **Поведение:**
     - `*ptr = 20;` — **Грешка при компилация!** Данните са само за четене.
     - `ptr = &b;` — **Позволено!** Самият указател може да бъде пренасочен към друг адрес.

2. **`const` е ВДЯСНО от звездичката `*` $\to$ Самият указател е константа (Константен указател):**
   ~~~cpp
   int* const ptr = &a;
   ~~~
   * **Четене отдясно-наляво:** `ptr` е константен (`const`) указател (`*`) към цяло число (`int`).
   * **Поведение:**
     - `*ptr = 20;` — **Позволено!** Стойността на адреса може да се променя през указателя.
     - `ptr = &b;` — **Грешка при компилация!** Указателят е „закован“ за първоначалния адрес и не може да се пренасочва.

3. **`const` и от ДВЕТЕ страни на звездичката $\to$ И указателят, и данните са константи:**
   ~~~cpp
   const int* const ptr = &a;
   ~~~
   * **Четене отдясно-наляво:** `ptr` е константен (`const`) указател (`*`) към константно цяло число (`const int`).
   * **Поведение:** И двете хвърлят грешка при компилация
     - `*ptr = 20;`
     - `ptr = &b;`

---

### Обобщение на позициите на `const`:

| Декларация | Какво е константа? | Може ли `*ptr = ...`? | Може ли `ptr = &...`? | Четене отдясно-наляво |
| :--- | :--- | :---: | :---: | :--- |
| `int* ptr` | Нищо | ✔️ Да | ✔️ Да | Указател към `int` |
| `const int* ptr` | Стойността (данните) | ❌ **Не** | ✔️ Да | Указател към константен `int` |
| `int* const ptr` | Самият указател (адресът) | ✔️ Да | ❌ **Не** | Константен указател към `int` |
| `const int* const ptr` | И двете | ❌ **Не** | ❌ **Не** | Константен указател към константен `int` |

---

### Константни референции (`const T&`)

Тъй като референцията по дефиниция никога не може да се пренасочва към друга променлива, за нея съществува само **константна референция към данни**:

~~~cpp
const int& ref = a; // ref е псевдоним само за четене
// ref = 50;        // Грешка: стойността не може да се променя през ref!
~~~

> **Важна особеност:**  
> Обикновена референция `int&` не може да се свърже с числов литерал или временна стойност (`int& r = 42;` е грешка при компилация).  
> Но **константна референция** `const int&` **може** да се свързва с литерали:
> ~~~cpp
> const int& ref = 42; // Напълно валидно в C++!
> ~~~

## 10. Указател към указател (Двоен указател)

Тъй като указателят сам по себе си е променлива, той също заема място в паметта и притежава собствен адрес. Възможно е да се дефинира указател, който съхранява адреса на друг указател:

~~~cpp
int value = 42;
int* ptr = &value;     // ptr сочи към value
int** pptr = &ptr;     // pptr сочи към ptr

std::cout << **pptr;   // 42 (двойно дереференциране)
~~~

~~~text
pptr (адрес 0x200) ----> ptr (адрес 0x106) ----> value (адрес 0x101, стойност 42)
~~~

## 11. Често допускани грешки

1. **Неинициализиран указател (Wild pointer):**
   ~~~cpp
   int* p; // Неинициализиран: съдържа неопределен (garbage) адрес в паметта
   *p = 10; // Опит за запис на произволен адрес — неопределено поведение
   ~~~
   *Добра практика:* Инициализирайте с валиден адрес или с `nullptr`: `int* p = nullptr;`

3. **Липса на проверка за `nullptr` преди дереференциране:**
   ~~~cpp
   int* ptr = nullptr;
   
   // Грешка:
   // *ptr = 5; // Срив на програмата
   
   // Правилен подход:
   if (ptr != nullptr) {
       *ptr = 5;
   }
   ~~~

4. **Деклариране на няколко указателя на един ред:**
   ~~~cpp
   int* p1, p2; // p1 е int*, но p2 е обикновен int!
   ~~~
   В C++ символът `*` се привързва синтактично към името на променливата, а не към общия тип. Ако искате два указателя на един ред, трябва да поставите звездичка пред всяко име (`int *p1, *p2;`) или най-добре — да ги дефинирате на отделни редове.
